# Security

Winwright lets an AI app use your desktop, so its safety rules matter as much as its features.

## Reporting a vulnerability

Please report privately through GitHub: **Security** tab → **Report a vulnerability**. Do not
open a public issue. Include what you did, what happened and what you expected; a short proof
of concept helps. You should get a reply within a week.

Especially wanted:

- anything that answers, hides, covers or skips Winwright's Allow/Deny dialog without a real
  person;
- a risky action (deleting, paying, running commands, closing programs, changing security
  settings) that is allowed without asking;
- reading password fields, keystrokes, or files Winwright is meant to refuse;
- a way for web pages, documents or other apps to steer Winwright through the AI app.

## Supported versions

Only the latest release gets fixes.
